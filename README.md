## 便宜的代价在哪？回程线路和延迟

同样标着“法兰克福”，线路不同，国内 ping 出来的数字能差一倍。德国 VPS 常见的回程线路有几种：联通 AS4837 是普通线路，便宜，晚高峰容易拥堵；AS9929 是联通精品网，回程质量好不少；AS10099 是联通 CUII；电信走 CN2 或 CN2 GIA；移动走 CMI 或 CMIN2。买德国 VPS，重点看回程走什么，机房名字反而没那么关键。

延迟要有个合理预期。各家测评的实测数据普遍落在 150–200ms，常见说法是 160–190ms 这个区间。这是物理距离决定的，优化线路能把回程修顺，不能把延迟压到香港的水平。有人写德国 VPS 能跑进 100ms，你可以直接关页面。

> 谁要是跟你吹德国VPS能跑进100ms，你可以直接关页面了——那是物理定律不同意，不是商家不同意。

IP 属性也要看。原生 IP 和广播 IP 是两回事，有些德国机房的 IP 一查归属地显示别的地方，那就是广播 IP。查归属可以用 ipip.net 这类数据库较新的站点。业务对 IP 归属敏感，下单前问清是原生还是广播，别等开通了才发现不对。

带宽和流量是另一个容易踩坑的地方。便宜套餐标的是共享带宽，商家一般只保证 99% 时间段达到标称值，国际出口晚高峰拥堵是常态。六六云给的是 1Gbps 端口，不等于任何时候都能跑满 1Gbps。流量还要看清单向还是双向计费。DigitalVirt 的测评里明确写的是双向计入，上传下载都算；六六云的套餐页没有把这句话写出来，下单前问一句。
